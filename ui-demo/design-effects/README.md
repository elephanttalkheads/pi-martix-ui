# ZION Design Effects Lab

三个 demo 均为本项目原创实现，不包含参考项目或电影的图像、字体、音频和代码副本。

- `matrix-wave.html`：把 Rezmason/matrix 的“固定字形 + 亮度波 + 高能头部 + bloom 后调色”机制改写成轻量 Canvas 2D。
- `crt-material.html`：把 cool-retro-term 的 dynamic / burn-in / static 多阶段 shader 结构改写成 CSS + Canvas 材质研究。
- `zion-command-hud.html`：结合 Matrix Reloaded 的环形透明 FUI 与 eDEX-UI 的稳定空间分区，使用原创 SVG 几何和合成标签。
- `index.html`：三个研究的本地入口。

直接打开 `index.html`，或在本目录启动任意静态文件服务器。所有动画均支持 `prefers-reduced-motion`。
