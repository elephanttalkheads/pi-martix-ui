## 2. agent 回复 UI 逐块重构(`agent-reply-*-proto.html`)

依据 `ui-demo/agent-reply-ui-handoff.md` §3.1–3.7 + 根 `DESIGN.md` 视觉宪章；每块三变体，浮条切换 + ↻ 重播。

### 3.1 消息块 `agent-reply-msg-proto.html`

主导隐喻：回复不是聊天泡泡，而是从模拟层显影出来的「传输件」。

| 变体 | 描述 | 设计巧思 | 状态 |
|---|---|---|---|
| A 亮度波显影 | 字形先就位（暗+微糊），亮度波逐行扫过，波峰近白、落定磷光绿；信号源菱形 ping + 发丝线生长 | 借 Rezmason 原则「移动的是亮度不是字形」 | ❌ 已否决（用户明确不采用） |
| B 电报穿孔带 | 左侧穿孔轨与正文逐行耦合；代码块做成证物板（角钉 + SPECIMEN 签 + 扫描线） | 行↔孔位 hover 联觉 | 未采用 |
| C 全息水印版 | 巨型描边标题水印 + 竖排时间戳 + 全息片代码块；入场整版从微俯仰角落定 | 叙事字形层（超大描边水印） | 未采用 |

### 3.2 思考块 `agent-reply-think-proto.html`

主导隐喻：思维链是「正在发生的认知过程」。浮条带 ◉ stream 按钮切流式/静止态。

| 变体 | 描述 | 设计巧思 | 状态 |
|---|---|---|---|
| A 脑波褶 | streaming 时 summary 旁活体脑波（SVG 折线流动+振幅呼吸）；展开体越新越亮 | 五行 opacity 0.38→1 沉降梯度——旧念头自然变暗 | 待定 |
| B 蒸馏柱 | 左侧细竖管内亮点循环滴落（静止坠底熄灭）；展开行带馏分刻度、自上而下冷凝（blur→清晰） | 思维被「蒸馏」成结论 | 待定 |
| C 折扇 | 展开时各行绕顶边 rotateX 阶梯打开；「思考中」=「思路」二字自身亮度呼吸 | 零新增元素，最克制 | 待定 |

### 3.3 工具链块 `agent-reply-trace-proto.html`

主导隐喻：工具调用是「能量被导入一个真实模块」。mock 含完成 + 执行中双态。

| 变体 | 描述 | 设计巧思 | 状态 |
|---|---|---|---|
| A 脉冲导管 | 去卡片化：左侧导管，run 时琥珀脉冲流入，ok 导管封口固化（带封口闪光），err 断裂成红虚线 | 导管三态即状态机 | 待定 |
| B 探针取样 | 取样玻片：SAMPLE 蚀刻签 + 读数刻度线；run 扫描片往复、ok 刻度按耗时比例固化 | `--dur-w` 把真实耗时映射成刻度宽 | 待定 |
| C 机械继电器 | DIN 导轨（凹槽纹理）+ 触点 LED 三态（琥珀呼吸/绿/红）+ 数码管耗时 + 铆钉参数抽屉 | 完成时触点 clack 冲击波；最 Zion 工业层 | 待定 |

### 3.4 diff 卡 `agent-reply-diff-proto.html`

主导隐喻：diff 是「一次物理写入在文件上留下的痕迹」。

| 变体 | 描述 | 设计巧思 | 状态 |
|---|---|---|---|
| A 烧录显影 | 新行逐行烧录（白热→冷却成绿），删行焦化（红闪→45% 余烬）；全部落定后**边框自绘一周**=校验环闭合 | 写入是有温度的；自绘环用 `viewBox 100×100 + pathLength=400 + vector-effect` 与像素尺寸解耦 | 待定（环偏移 bug 已修） |
| B 变异缝 | 删行组左滑 16px 半隐消散、新行组自右滑入，中间夹红绿锯齿「变异缝」（闪现后定 55%） | 新旧交替物化为伤口缝合线 | 待定 |
| C 光刻 | 下缘高亮光束自上而下扫过一次，行只在光束扫过后逐行裁切显影 | 「差异是被光刻进文件的」 | 待定 |

### 3.5 结算行 `agent-reply-settle-proto.html`

主导隐喻：回合闭环是「给这次执行盖上封印」。每版含 ok + interrupted 双样。

| 变体 | 描述 | 设计巧思 | 状态 |
|---|---|---|---|
| A 压印 | ◆ 从 140% 压下（回弹+冲击波），文字字距 0.5em→0.1em 弹回，发线自绘 | 火漆印 | 待定 |
| B 沉降 | 统计拆成独立「沉降件」带模糊逐一落位，◆ 最后落下轻弹，发线=地面最后淡入 | 回合结束读作能量沉淀 | 待定 |
| C 封存带 | ◆ 锚点后封存带向右展开 + EOL 方块闪两下；**中断版带尾撕裂锯齿、无 EOL** | 「被封存」vs「被撕断」形态一眼可辨 | 待定 |

### 3.6 雨轨 `agent-reply-rail-proto.html`

主导隐喻：左轨是回合的「生命体征记录仪」。每版左右并置活动/闭环双态（canvas）。

| 变体 | 描述 | 设计巧思 | 状态 |
|---|---|---|---|
| A 心电图轨 | 纵向生命迹线：正弦蠕动基线 + 随机尖峰脉冲（近白辉光）；闭环拉直成平线凝 ◆ | 回合的「活着」=字面心电 | 待定 |
| B 蓄水槽 | 字形滴落汇入底部水位（水面亮线，水位=回合内容量，cap 70%）；闭环整柱冻结凝 ◆ | 水位是真实内容量的物化 | 待定 |
| C 磁带纹 | 短划纹持续上行（磁带嘶声），6% 高亮簇；闭环纹带定格凝 ◆ | 最安静的一款 | 待定 |

### 3.7 流式光标与中断标记 `agent-reply-caret-proto.html`

主导隐喻：光标是「写入头」——它活着文本就在生长，它被掐灭就是中断。浮条 ◉ 切流式/中断场景。

| 变体 | 描述 | 设计巧思 | 状态 |
|---|---|---|---|
| A 彗尾写入头 | 2px 竖条 + 左拖双层彗尾辉光呼吸；中断时彗尾**倒吸归零**（变红收缩）+ 中断文 glitch 切片一次 | 中断=写入头被拔走 | 待定 |
| B 字形蛾 | 光标是 120ms 翻滚的 Matrix 字形蛾（非实色块）；中断文从乱码逐位锁定成真字 | 与注入解码同语言：「被掐断的传输」 | 待定 |
| C 光标即状态 | 经典 8px 方块 blink；中断时光标红闪压扁坍缩、然后「长成」中断标记 | 光标之死即中断，叙事最完整 | 待定 |
