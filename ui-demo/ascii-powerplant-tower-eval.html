POWER PLANT TOWER EVAL — 瓶刷圆柱复刻

真圆柱世界坐标建模 + 放射 pod 刺 + 环带甲板 + 塔基舱海 // 左近景 · 右远景 // 彩色横带 = 会话刻痕

V1 · 完整（红尖 + 环带 + 舱海）

全部通道开。pod 尖 #ff4a3d 暖红——最接近电影画面，但与 ERROR 状态色（#ff5364）只差一档色相，语义冲突风险需要在真机里判断。

V2 · 绿尖（规避红色语义冲突）

几何完全相同，刺尖改 Matrix 绿。牺牲电影的色彩签名，换取与 STATUS 字典零冲突。若远景下瓶刷感仍成立，这条是最安全的落地路径。

V3 · 稀疏红尖无舱海（对照）

刺密度减半、去掉塔基舱海。用来分离变量：瓶刷感主要来自刺还是来自舱海氛围？若与 V1 差距小，说明可以省掉舱海的点数开销。
