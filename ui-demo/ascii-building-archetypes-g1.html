METROPOLIS 退台塔 · HL2 CITADEL 方尖碑 · WALLACE 巨石 // 左列近景 · 右侧小图为远景（雾衰减代理） · 亮绿横带 = 会话字形带

1.2 METROPOLIS 退台塔

婚礼蛋糕式 3 级退台 + 中轴尖顶。竖边 |、拐角 + 与退台几何严丝合缝；退台台面天然承载会话带（楼层=会话同构）。

1.3 HL2 CITADEL 方尖碑

上细下粗，顶部密度渐隐 = 入云。基座 < > 斜线扶壁；立面窄，会话带只能做 5–7 字形短带——代价最大的候选。

1.4 WALLACE 巨石

顶平实心梯形，顶部一点孤光。内部高密度实心填充表达「无窗巨石」；底部雾线密度骤降；会话带 = 凿进石面的刻痕。
