ARCHETYPE GALLERY G2/3 — 剪影选型评估

TRON MCP 塔 · GITs 新港市水线楼 · AKIRA 亮窗方楼 // 左列近景 · 右侧小图为远景（雾衰减代理） · 亮绿横带 = 会话字形带

1.5 TRON MCP 塔

矩形塔身 + 顶部双角天线，内部电路走线网格。辨识度全在内部纹理，远景会退化成默认方楼——调研标记的高风险项，远景列验证这一点。

1.6 GITs 新港市水线楼

平顶方楼 + 侧面外挂物 + 右侧天桥 + 底部水位线。辨识度靠「群像+天桥+水线」，单栋看是普通方楼——定位是默认/背景楼型，不是旗舰地标。

1.7 AKIRA 亮窗方楼

平顶方塔无收分，25% 窗格确定性随机提亮。轮廓与默认楼相同，辨识度在立面光点节奏；会话带与随机亮窗的对比度是全候选最好的。
