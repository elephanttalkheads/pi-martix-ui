# Matrix Drive Vault 独立侧边栏：测量与复刻基线

本文记录 `http://127.0.0.1:3080/` 完整左侧边栏的测量结果，以及独立 Demo `ui-demo/matrix-drive-vault-sidebar.html` 的尺寸映射。

## 测量说明

- 计划工具：Kimi WebBridge，借用用户当前打开的真实 Chrome 标签页。
- 实际状态：守护进程成功启动，但浏览器扩展返回 `no extension connected`。遵照 Kimi WebBridge skill 的失败处理规则，没有伪造连接或继续调用。
- 回退工具：本机 Chrome 151 的只读 CDP 页面，加载同一地址并通过 `getBoundingClientRect()` / `getComputedStyle()` 读取。
- 回退视口：`1518 × 804 CSS px`，`devicePixelRatio = 1`。
- 用户参考截图：侧边栏图像为 `330 × 870px`。独立 Demo 以该截图宽高作为最终画布，同时保持回退实测中的纵向尺寸、内边距和步进。

因此，下表中的“原页基线”是 CDP 回退实测值，不冒充 Kimi 对用户现有标签页的读数。

## 独立 Demo 的 330px 映射

用户截图宽度为 `330px`，因此保留左右根内边距 `12px`，让主要可用宽度随侧栏增至约 `306px`。用户要求移动的“新会话”按钮不再占用原来的 `38px + 8px` 独立行，而是作为第四个 `28 × 28px` 图标放入工作区工具栏。

| Demo 元素 | 最终实测尺寸 | 说明 |
| --- | ---: | --- |
| 侧栏 | `330 × 870` | 固定演示画布，可被 `100vh` 裁切 |
| 品牌行 | `305 × 60` | DeepSeek ZION 像素文字 Logo + `56×56` Neo + `28×28` 收起图标 |
| 工作区工具栏 | `309 × 36` | 搜索 / 视图 / 添加工作区 / 新会话均为 `28×28` 图标 |
| 工作区滚动区 | `321 × 698` | 4 个工作区、11 个会话 |
| 机柜顶 | `303 × 34` | 琥珀热痕重型顶梁；映射工作区标题行 |
| 单盘位机柜体 | `303 × 34` | 冷青导轨与黑色空腔；只表达结构 |
| 会话硬盘 | `303 × 32` | 在盘位 `y=2px`；磷光绿独立数据盒 |
| 底部设置区 | `305 × 50` | 内部按钮高度 `42px` |

工作区高度仍遵循：

```text
H_workspace(N) = 34 + N × 34
```

## Neo 神经线缆几何

- Neo 使用 `src/renderer/src/assets/neo-avatar/neo-side-profile-neural-port-v5.png`，原图 `256 × 256`，Demo 中显示为 `56 × 56` 并启用 `image-rendering: pixelated`。
- 用户蓝圈指示的裸露线头取原图近似坐标 `(46, 144)`，而不是生产实现文档中的旧后脑接口锚点 `(82,114)`。
- 线缆是程序化 SVG，包含 `10px` 黑色线床、`6px` 生物机械护套、`2px` 磷光神经和 `1px` 数据缝线四层。
- 当前截图实测：线缆起点 `(237.1, 40.5)`；终点 `(307.5, 202)`；当前硬盘接收器中心 `(307.5, 202)`，终点误差为 `0px`。
- 点击任一会话只改变当前会话和线缆终点；工作区不会折叠。搜索、视图、添加工作区、新会话、收起侧栏只复刻图标，不实现产品功能。

## 素材层级差异

- **机柜顶**：暖琥珀、铜锈、厚顶梁和文件夹标识，表达“工作区身份”。
- **机柜体**：冷青色左右导轨、螺钉和黑色空腔，表达“容量结构”。
- **会话硬盘**：绿黑前面板、活动灯、接收端口和当前会话增亮，表达“真实数据对象”。

三层素材均由 CSS 硬边、重复渐变、裁角和像素阴影构成，不依赖固定分辨率整张背景图，可以直接进入 Electron/Vite 渲染层并随侧栏宽度伸缩。
