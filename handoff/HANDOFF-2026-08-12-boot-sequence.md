# HANDOFF — 开屏序列（待机循环）demo — 2026-08-12

## 任务状态：已中止（效果未达预期），待下轮重新定义验收标准

## 目标（原始需求）

做一个 agent 启动时的开屏动画 HTML demo：参考《2001 太空漫游》星门穿越段
（`C:\Users\DELL\Videos\屏幕录制\屏幕录制 2026-08-12 235206.mp4`，8s slit-scan 光廊）
的**运镜方式和场景构图**，内容替换为黑客帝国数字雨（基础算法见
`ui-demo/icon/react/agent-ui-design-spec.md` §4.1）。

产品语义（用户拍板）：启动 agent 后默认无会话，**循环播放**开屏动画；
用户选择会话或发送消息时退出动画进入主界面。

## 已落地的决策（grilling 四轮，用户均确认）

- **纯氛围驻留态，不是加载页**：不显示进度、不阻塞操作；退出只看用户操作。
- 单文件零依赖 canvas 2D demo：`ui-demo/boot-sequence-demo.html`。
- 字符集沿用 §4.1 半角假名；单色磷光绿纪律，灭点允许白热核心。
- 无限循环 = 稳态隧道 + 20-30s 呼吸调制（无可见循环点）。
- 每 ~15s 在画面中心扰码解密出 `ZION`（复用蠕虫解密语言），锁定后镜头"穿过"它（放大+淡出）。
- 底部常驻状态行 `ZION://agent-console — 选择会话或输入指令 █`（退出引导）。
- 退出 = 任意键/点击 → **冲入灭点**（1.1s 加速 + 白热吞屏）→ 结束卡，R/点击重播。
- 声音：WebAudio 全合成（低频嗡鸣 + 白噪 + 解密滴答），右下角 `[SND]` 开关，
  持久化 `localStorage.zion.snd`，首次手势后才出声（浏览器策略）。
- `prefers-reduced-motion` → 静态走廊帧。
- **运动学约束（第三轮用户翻案）**：数字雨必须始终**从上往下落**，禁止径向外飞。
  前冲感全部来自镜头运动，不来自内容运动。
- **走廊构图（第四轮用户翻案）**：雨帘不得垂直正面逼近镜头；左半屏雨帘逼近时向左扫开、
  右半屏向右扫开；中央留通道通向灭点光；通道内只留永不逼近的远景细帘。

## 三个被否的版本（教训：下轮先对齐"参考画面"再写代码）

1. **v1 径向星门**：字符从中心灭点向外辐射。被否：雨必须向下落。
2. **v2 纵深雨幕**：垂直雨帘在 Z 轴分层，镜头直线前冲。被否：帘"正脸糊上来"，

   （`CORRIDOR_W`）+ 远景帘（`FAR_HOLD`）。用户看完仍"始终不太满足"，中止。
   **未收集到 v3 具体哪里不对**——这是下轮开工前必须问的第一件事。

## 下轮开工建议（按优先级）

1. **先问清 v3 的不满点**：是构图（走廊感不够/通道太宽太窄）、节奏（镜头速度/呼吸幅度）、
   密度/字号、灭点光太强、ZION 节拍位置，还是整体方向就错了（也许用户要的是更纯粹的
   2D 数字雨开屏，2001 只要一个构图暗示）？建议让用户在 v3 截图上圈注，或提供一张
   参考静帧。视觉评审可派 `vision` subagent（AGENTS.md Subagents 节）。
2. 可调参数都集中在文件顶部常量区：`LANE_DRIFT / CORRIDOR_W / N_COLS / N_FAR /
   FAR_HOLD / BREATH_PERIOD / BEAT_EVERY / camSpeed 基值(1.05)`。
3. 若方向改为"纯 2D 雨 + 构图暗示"，v1/v2 的 3D 投影代码可整体废弃，
   §4.1 单层雨 + 灭点光 + 节拍 + 退出白爆即可，半天工作量。
